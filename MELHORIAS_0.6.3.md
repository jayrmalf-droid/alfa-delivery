# AlfaDelivery PRO 0.6.3 — Refinamento da interface (prévia)

- Menu móvel fecha pela tecla Escape.
- Bloqueio da rolagem de fundo enquanto menu móvel está aberto.
- Botão do menu expõe estado expandido para tecnologias assistivas.
- Menu possui identificador e rótulo de navegação.

Esta é uma prévia de refinamento pontual, não uma revisão integral de todos os formulários e mensagens.
Não altera banco de dados ou regras de negócio.
