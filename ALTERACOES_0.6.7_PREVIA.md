# AlfaDelivery PRO 0.6.7 — Prévia do painel de pedidos

Base: projeto 0.6.6 enviado pelo usuário.

Alterações: indicadores de novos, em preparo, prontos/em entrega, concluídos hoje e tempo médio aproximado dos concluídos hoje; ações de impressão da página, exportação CSV dos pedidos filtrados, botão para abrir cardápio, filtros avançados por data, pagamento e bairro; layout responsivo.

**Atenção:** prévia não homologada. A compilação não pôde ser executada neste ambiente (dependência xtend ausente do cache e Node 22 em vez de >=24). Rodar npm ci, npm audit, npm run build e npm start no Windows e testar em cópia do banco.

Não inclui dados pessoais, backups, arquivos .env ou banco de dados. Os arquivos src/data/initialData.ts e bannerSeeds.ts foram repostos de versão anterior para completar a distribuição e precisam ser verificados quanto à compatibilidade.
